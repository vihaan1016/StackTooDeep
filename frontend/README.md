# S2D AI Compute Hub

Decentralized AI Compute on Flux.

## Project info

This project serves as the frontend hub for managing AI compute resources, processing payments via the x402 protocol, and interacting with LLMs on the Flux network.

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd flux-ai-hub

# Step 3: Install dependencies
npm i

# Step 4: Start development server
npm run dev
```
